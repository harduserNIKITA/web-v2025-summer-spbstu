4.1. Создать класс BlogPost с полями:
• id — уникальный идентификатор (число)
• title — заголовок поста (строка)
• tags — массив тегов (строки)
• comments — массив объектов комментариев с полями author (строка) и 
text (строка)
Реализовать методы:
31
• addTag(tag) — добавить тег
• removeTag(tag) — удалить тег
• addComment(comment) — добавить комментарий
• геттер commentCount — количество комментариев
4.2. Дан массив блог-постов:
• Реализовать функцию, которая группирует посты по тегам (Map)
• Реализовать функцию, возвращающую уникальные теги (Set)
• Реализовать функцию, которая группирует посты по количеству 
комментариев (Map)
• Реализовать функцию, которая возвращает посты с заданным тегом
• Реализовать функцию, которая возвращает список всех авторов 
комментариев
4.3. Реализовать пользовательский интерфейс:
• Список карточек постов. В каждой карточке отображать: заголовок, теги, 
список комментариев, количество постов.
• Формы: добавление тега, добавление комментария 
• Кнопка "Удалить пост", “Добавить пост”, “Добавить тэг”, “Удалить тэг”, 
“Добавить комментарий”
• При любых изменениях автоматически обновлять пользовательский 
интерфейс
• Все операции добавления/удаления выполнять асинхронно через Promise
+ setTimeout()
• Использовать local storage для сохранения текущего списка студентов при 
закрытии вкладки.
